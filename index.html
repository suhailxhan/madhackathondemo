ESP32 #1 pseudo-code (simplified)
setup: wifi.connect(); mqtt.connect(); oled.init()
loop:
  if button1 pressed (debounced 50 ms):
     r3 = esp_random()              // hardware RNG
     mqtt.publish("chai/request", r3)
  on mqtt "chai/result": oled.show(winner, "21 steps instead of 1")
  if button2 pressed: reset()
ESP32 #2 pseudo-code (simplified)
on mqtt "chai/approved"(side):
  servoA.write(90)                    // release marble
  servoB.write(side == LEFT ? 30 : 150) // gate
  wait for IR1 (max 10 s)             // right path?
  wait for IR2 (max 10 s)             // at lever?
  servoC.swing(); bell.ring()
  mqtt.publish("chai/done")
timeout: pick side locally and continue
